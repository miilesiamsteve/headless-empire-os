# Operating principles

## What this OS is for

A practical hub for planning, tasks, content, AI agents, and durable knowledge. It should make the **next useful action** obvious.

## Design principles

1. **Daily workflow first** — if it does not help today, rethink it.  
2. **Content is first-class** — ideas should become assets.  
3. **Agents need briefs** — context, constraints, output format, review.  
4. **Capture messy, store clean** — inbox → proper folder.  
5. **Archive, don’t delete** — history without clutter.  
6. **Boring structure** — use it every day.  
7. **Human-led** — agents operate under authority.  
8. **Private by default** — public is opt-in.

## Review cadence

| Cadence | Primary files | Purpose |
|---------|---------------|---------|
| Daily | `00-command-center/TODAY.md` | Execute and capture |
| Weekly | `WEEK.md` + weekly plan | Outcomes and content |
| Monthly | `01-planning/monthly/` | Themes and metrics |
| Quarterly | `01-planning/quarterly/` | Strategy / OKRs |
