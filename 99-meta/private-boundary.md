# Private boundary

## Two editions

| Edition | Repo | Contents |
|---------|------|----------|
| **Public starter** | `HeadlessEmpire/headless-empire-os` | Empty templates, fictional examples |
| **Your private OS** | Your private GitHub repo | Real priorities, people, money, drafts |

The public case study at [mikesblogdesign.com/ceo-os](https://mikesblogdesign.com/ceo-os) describes *how* a live OS works. It is not a dump of private files.

## Safe in public

- Folder structure and rituals  
- Blank templates  
- Fictional sample operator content  
- Links to public products and docs  

## Keep private

- Customer and employee details  
- Financials, legal, health  
- Unreleased strategy and passwords  
- Real TODAY / WEEK / NOW filled with sensitive context  
- Agent logs that quote private material  

## Recommended setup

1. Use this repo as a **template**.  
2. Create a **private** repository for your live OS.  
3. Optionally keep a thin public fork with only sanitized docs.  
4. Never force-push private history into the public template.
