# Contributing

Thanks for improving the public Headless Empire OS starter.

## What belongs here

- Clearer structure, rituals, templates, and agent guidance  
- Better examples using **fictional** operators only  
- Links and docs that match headlessempire.com positioning  

## What does not belong here

- Real company data, people dossiers, financials, or private SOPs  
- Credentials or `.env` contents  
- One operator’s live TODAY/WEEK/NOW content  

## How to contribute

1. Open an issue describing the gap.  
2. Fork and PR with focused changes.  
3. Update `99-meta/changelog.md` for meaningful structure changes.  
4. Keep voice aligned with: *Human-led. Agent-operated. Always learning.*
