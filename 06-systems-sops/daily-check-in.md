# SOP: Daily check-in

## Purpose

Start the day with clear human and agent work.

## Steps

1. Open `00-command-center/TODAY.md`.  
2. Note yesterday’s shipped / learned / open.  
3. Choose **Top 3 outcomes**.  
4. Scan `waiting-for.md` and `delegated.md`.  
5. Dispatch agent briefs only for work that needs leverage.  
6. Capture noise in `inbox.md`, not in Top 3.  

## Done when

Top 3 written, first action obvious, agents briefed if needed.
